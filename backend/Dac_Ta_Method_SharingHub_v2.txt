Use Case Nghiệp vụ | Use Case UC5.1 - Đăng ký tài khoản người dùng mới
Tầng Controller (Presentation) | Class: AuthController Method: register(@Body() dto: RegisterDto) Decorators: @Post('register') HTTP Status: 201 CREATED
Tầng Service (Business Logic) | Class: AuthService Method: register(dto: RegisterDto) Return Type: Promise<Object>
Tầng Data Access (Prisma / Cloud) | ORM API: prisma.nguoiDung.findUnique(), prisma.nguoiDung.create() Bảng tác động: nguoi_dung, nguoi_dung_ho_so, ho_so_uy_tin
Input Arguments | ● dto (RegisterDto): Gồm email, so_dien_thoai, mat_khau, ho_ten.
Return Value | Object: Thông điệp thành công và thông tin tài khoản người dùng vừa tạo (loại bỏ mat_khau_hash).
Pre-conditions | ● Email chưa từng tồn tại trong CSDL. ● Số điện thoại (nếu có) đúng định dạng và chưa từng đăng ký. ● Mật khẩu >= 6 ký tự.
Post-conditions | ● Bản ghi nguoi_dung tạo mới với vai_tro = 'THANH_VIEN', trang_thai = 'HOAT_DONG'. ● Tự động tạo bản ghi nguoi_dung_ho_so và ho_so_uy_tin (100 điểm ban đầu).
Processing Steps (3 Tầng) | 1. [Controller] Tiếp nhận HTTP POST /auth/register, validate RegisterDto. 2. [Service] Kiểm tra email/SĐT trùng lặp trong CSDL. 3. [Service] Mã hóa băm mật khẩu bằng bcrypt (saltRounds=10). 4. [Data Access] Thực thi chèn bản ghi vào 3 bảng nguoi_dung, nguoi_dung_ho_so, ho_so_uy_tin. 5. [Controller] Phản hồi HTTP 201.

Tầng Service (Business Logic) | Class: AuthService Method: login(dto: LoginDto) Return Type: Promise<Object>
Tầng Data Access (Prisma / Cloud) | ORM API: prisma.nguoiDung.findFirst() Bảng tác động: nguoi_dung
Input Arguments | ● dto (LoginDto): Gồm tai_khoan (Email/SĐT) và mat_khau.

Pre-conditions | ● Tài khoản Email/SĐT tồn tại trong CSDL. ● Mật khẩu khớp với chuỗi mã hóa băm bcrypt. ● Tài khoản không ở trạng thái BI_KHOA.
Post-conditions | ● Chuỗi mã thông báo bảo mật JWT Access Token được ký thành công.
Processing Steps (3 Tầng) | 1. [Controller] Nhận thông tin đăng nhập từ Client. 2. [Data Access] Tìm kiếm người dùng theo Email/SĐT. 3. [Service] Kiểm tra tài khoản không bị khóa. 4. [Service] Đối soát mật khẩu băm bằng bcrypt.compare(). 5. [Service] Ký cấp JWT Token qua JwtService.sign(). 6. [Controller] Phản hồi HTTP Code 200 kèm access_token.
